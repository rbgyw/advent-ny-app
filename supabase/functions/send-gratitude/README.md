# Праздничная почта — пример подключения

Клиент вызывает `supabase.functions.invoke('send-gratitude')`. Попап появляется только после ответа `{ "sent": true }`. В примере используется Resend; обработчик можно адаптировать под корпоративную почту, сохранив контракт.

1. Подтвердите домен отправителя в Resend. Выберите отдельный адрес праздничной почты.
2. Задайте серверные секреты через Supabase Dashboard → Edge Functions → Secrets:

```dotenv
RESEND_API_KEY=re_ваш_ключ
GRATITUDE_FROM=Праздничная почта ГЕРОФАРМ <advent@ваш-подтвержденный-домен.ru>
APP_ORIGIN=https://адрес-приложения.ru
```

`SUPABASE_URL` и `SUPABASE_ANON_KEY` предоставляет Supabase. Почтовый ключ нельзя добавлять в переменные `VITE_*`.

3. Из корня проекта выполните:

```powershell
supabase functions deploy send-gratitude --no-verify-jwt
```

`--no-verify-jwt` отключает проверку старым шлюзом: обработчик самостоятельно проверяет пользовательский JWT через `/auth/v1/user` до отправки. Пользователь должен быть авторизован, подтвердить корпоративную почту и иметь открытое задание `task-08`. REST-запросы используют его JWT и RLS.

Запрос содержит `taskId`, UUID v4 `requestId`, `anonymous`, `senderName`, `recipient`, `message`. Анонимное письмо не содержит имени и адреса автора; авторизация при этом обязательна. Содержание отправляется обычным текстом и не сохраняется в ответе задания; после подтверждения Resend RPC `save_task_progress` сохраняет `{ "sent": true }`.

При повторе неизменённого запроса клиент сохраняет `requestId`. Resend хранит ключи идемпотентности 24 часа. Пример не даёт бессрочную защиту от повторов и не ограничивает число разных писем; перед массовым запуском добавьте постоянный журнал отправок и серверный лимит в зависимости от правил проекта. Успех означает принятие письма почтовым провайдером; доставку можно отслеживать его webhook.

Пример проверяется локальными тестами с подменённой сетью. Реальные секреты и домен не настроены, функция автоматически не развёртывается.

Документация: [Resend Send Email](https://resend.com/docs/api-reference/emails/send-email), [ключи идемпотентности](https://resend.com/docs/dashboard/emails/idempotency-keys), [Supabase getUser](https://supabase.com/docs/reference/javascript/auth-getuser).
