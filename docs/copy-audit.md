## Остальные расхождения

- Правила участия: документ описывает обязательные окна как оранжевые с золотой окантовкой, текущий текст правил — как золотые с красной окантовкой. Расцветка и текст оставлены без изменения.
- Карта «Смерть»: различается только пробел перед точкой после названия.
- Карта «Солнце»: документ — «одна из самых светлых карт. Она…»; код — «один из самых светлых арканов. Оно…».
- Карта «Мир»: документ — «эта карта символизирует завершение этапа…»; код — «последний Старший аркан. Он говорит о завершении этапа…».
- Миграция `004_seed_tasks.sql` содержит тестовые названия и описания. Фактические данные production и специальные серверные RPC недоступны для проверки в этой среде.

Это перечень расхождений исходного приложения, а не регрессий оптимизации. Внедрение отсутствующих игровых механик, перенос дней и замена проверяемых ответов требуют отдельной реализации с согласованными серверными контрактами.
