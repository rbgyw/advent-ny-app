# Чёткость карточек 5 декабря

Карточки рисуются сразу в размере ячейки CSS Grid, без `cardScale`, `--card-scale` и масштабирования готового слоя через `transform: scale(...)`. Координаты и размеры упаковок переводятся из исходного макета 73 × 101 px в проценты. Размеры SVG-фонов, их выступ на полпикселя и положение декоративной звезды масштабируются в той же пропорции. Исходные PNG из `assets/dec_5` сохранены без изменений.

Переворот выполняется через Vue `Transition`: длительность 480 мс, исходная easing-функция и направление открытия/закрытия сохранены. Перспектива, поворот и скрытие обратной стороны применяются только на время перехода. После него классы перехода удаляются, и видимая упаковка не остаётся в постоянном 3D-слое. При reduced motion переход отключён.

`ResizeObserver` продолжает следить за фоном и обновлять градиент. Наблюдение за игровым полем удалено. Перемешивание, сопоставление, таймеры ходов, счётчики и сохранение прогресса не менялись.

## Проверка

- Chromium: визуально просмотрены открытые карточки на ширинах 393 и 1440 px при DPR 1, 2 и 3; расположение и пропорции всех восьми упаковок проверены относительно исходного макета.
- На каждой комбинации размера/DPR PNG сравниваются пиксель в пиксель с вариантом, в котором принудительно отключены все 3D-эффекты. Проверяется восстановленный экран и карточка после настоящего переворота. Отличающихся пикселей нет. SVG-фоны исключаются из этого сравнения, чтобы отдельно оценить растровые изображения.
- Проверены промежуточная фаза переворота, несовпадение и обратный переворот, найденная пара, счётчик ходов и восстановление после перезагрузки в обычном режиме и с reduced motion.
- 9 браузерных сценариев прошли, включая существующий сценарий нахождения восьми пар и сохранения `{ solved: true }`.
- Typecheck, 478 unit-тестов и production build прошли. Build audit подтвердил ссылки на все файлы сборки (351 файл).

Браузерные проверки используют локальные сетевые фикстуры. Production и deploy не затрагивались.
