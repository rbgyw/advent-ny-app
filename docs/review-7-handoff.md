## Видео в попапе второго задания

Ролик подарка из отдельного вложения `-5538377309462799870.mp4` подключён в `SecondTaskScreen.vue` через `PopupLoopVideo.vue`. Локальный файл — `src/assets/cipher/gift.mp4`: H.264/AAC, 1280 × 720, 17,37 с. Контейнер подготовлен для быстрого старта без перекодирования изображения и звука. Видео создаётся только при открытом попапе, проигрывается автоматически без звука, по кругу и внутри страницы. Стандартные элементы управления, Picture-in-Picture, удалённое воспроизведение и контекстное меню видео выключены. При закрытии попапа или уходе со страницы воспроизведение останавливается, источник освобождается.

Вложение «правки.zip» по-прежнему недоступно из-за лимита переноса 32 МиБ. Отдельное видео не заменяет ожидаемые музыкальные файлы из таблицы выше.

## Подключение при публикации

Изменения подготовлены в Git, реальные Supabase и почтовая доставка не изменялись.

1. Применить миграции `011_swap_december_3_and_4.sql` и `012_validate_basic_sport_submission.sql` после уже существующих миграций. Первая меняет окна и даты, сохраняя идентификаторы заданий и ответы: 3 декабря — `task-04` (кроссворд), 4 декабря — `task-03` (воспоминания). Вторая проверяет готовую фотографию и для базового уровня спорта с автоматическим зачётом.
2. Для входа по коду настроить шаблоны писем Supabase Auth на показ `{{ .Token }}` (вместо одной ссылки), включая шаблоны входа и подтверждения регистрации. Клиент использует `signInWithOtp` / `verifyOtp` и форму из шести цифр.
3. Для задания 8 настроить и развернуть `send-gratitude` по инструкции в `supabase/functions/send-gratitude/README.md`: Postbox, серверные `POSTBOX_*`, точный `APP_ORIGIN`, миграция журнала 013. Доменную политику переключают независимые VITE/серверный флаги; серверные Auth Hooks подключаются вручную по `docs/email-domain-policy.md`. Секреты хранятся только на сервере. Автоматические тесты не отправляют настоящие письма.
