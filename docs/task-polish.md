## Что отложено

По уточнению пользователя автоматическое одобрение через 24 часа и ручная модерация **не реализуются**. Новых RPC, миграций или Cron нет. UI не засчитывает фотографию по таймеру. Текущий базовый уровень спорта, который завершается сервером сразу, не переведён в ожидание проверки; серая отметка относится к фактическому `submitted_for_review` без `status=completed` (в спорте — прежде всего advanced/team).

Для будущей модерации потребуется отдельно спроектировать серверные права, дату отправки и результаты проверки. Пока состояние «На проверке» сохраняется до изменения статуса сервером.
