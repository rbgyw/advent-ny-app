## Игра на 20 декабря

По идентификатору пользователя и задания выбирается одна целевая звезда из всех кликабельных звёзд. В `localStorage` сохраняются только число использованных попыток и список выбранных звёзд. На поиск даётся 10 попыток; каждая звезда проверяется один раз. Цель вычисляется заново при открытии, поэтому не меняется после перезагрузки и не требует локального хранения. Выбор целевой звезды в любой из 10 попыток даёт успех; выбор 10 других звёзд завершает поиск без успеха.

В Supabase через `save_task_progress` сохраняется финальный результат: `{ "wish_made": true }` после «Загадать желание» либо `{ "search_exhausted": true }` после десятой неудачной попытки, с признаком завершения задания. После подтверждения сервером локальные данные поиска удаляются. При ошибке сохранения они остаются для повторной отправки. Старые локальные записи мигрируются без сохранённого результата и старого порога нажатий.

Все результаты, включая окончание попыток, показываются в попапе. При возвращении в завершённое задание отображается только попап с результатом из Supabase. Старые серверные записи с `wish_made` поддерживаются. Фон страницы — CSS-градиент; координаты звёзд и векторные слои масштабируются вместе с изображением неба. Счётчик попыток и обводка выбранных звёзд скрыты.

Для визуальной проверки откройте незавершённое задание и выполните в DevTools Console. Скрипт выводит постоянный ID целевой звезды и временно подсвечивает её; попытки и БД не меняются. Для провала выберите 10 других звёзд. После сохранения результата повторная проверка игры требует сброса выполнения задания.

```js
(() => {
  const board = document.querySelector('.guiding-search');
  const stars = [...(board?.querySelectorAll('[data-star-id]') ?? [])];
  if (!stars.length) return console.warn('Откройте незавершённое задание 20.');
  let hash = 2166136261;
  for (const char of board.dataset.searchIdentity) {
    hash = Math.imul(hash ^ char.charCodeAt(0), 16777619);
  }
  const target = stars[(hash >>> 0) % stars.length];
  console.log('Искомая звезда:', target.dataset.starId);
  target.scrollIntoView({ block: 'center', behavior: 'smooth' });
  target.animate([{ outline: '3px solid lime' }, { outline: '3px solid transparent' }], { duration: 1000, iterations: 10 });
})();
```

## Игра на 19 декабря

Попытки и абсолютное время окончания текущей минуты сохраняются в `localStorage` отдельно для пользователя и назначения задания. Перезагрузка и уход со страницы не продлевают время. Один истёкший раунд расходует одну из пяти попыток; промахи и увеличение не расходуют попытки. Локально найденный Поджик сохраняется до подтверждения результата сервером, чтобы можно было повторить сохранение после сбоя сети.

Нажатие на картинку только ставит метку. Проверка выполняется кнопкой «Проверить выбор», которая остаётся доступной после промахов. Центр правильного выбора — 153 px слева и 65 px сверху внутри картинки размером 316 × 419 px в макете; принимаются точки в круге радиусом 20 px. При изменении ширины или увеличении область масштабируется вместе с картинкой.

В Supabase через существующий `save_task_progress` отправляется только `{ "solved": true }` с признаком завершения. Данные неуспешных раундов, координаты и время в БД не отправляются. Завершённый статус из БД имеет приоритет над локальным прогрессом.

## Публикация историй на 23 декабря

`public/collections/memories.json` содержит массив историй. Укажите `name` и `text`. Поля `photoUrl` и `photoAlt` для фотографии и её описания необязательны.

```json
[
  {
    "name": "Имя сотрудника",
    "text": "Текст воспоминания",
    "photoUrl": "images/memory.jpg",
    "photoAlt": "Коллеги на корпоративном мероприятии"
  }
]
```

После первой публикации приложения можно заменить `collections/memories.json` в каталоге готового сайта без пересборки. Имена, тексты и фотографии из подборки доступны по публичным URL. Если фотография уже размещена, укажите её HTTPS-адрес. Относительные пути к фотографиям считаются от каталога `collections/`.

## Публикация киноподборки на 24 декабря

`public/collections/movies.json` содержит массив фильмов. Обязательны `title` и числовой `year`. Поля `comment`, `imageUrl` и `imageAlt` можно пропустить.

```json
[
  {
    "title": "Название фильма",
    "year": 1990,
    "comment": "Почему коллега советует этот фильм",
    "imageUrl": "images/movie.jpg",
    "imageAlt": "Кадр из фильма"
  }
]
```

После первой публикации приложения замените `collections/movies.json` в каталоге готового сайта. Для изображений действуют те же правила, что и для фотографий историй.
